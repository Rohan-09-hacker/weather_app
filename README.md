# SkyCast Weather Forecast App

A clean, modern desktop weather dashboard built with Python that leverages real-time API streams and automatic location detection to deliver instant meteorological data.

## 🚀 Features
* **Auto-Location Detection:** Automatically detects your current city on startup by parsing your public IP address using network geolocation pipelines.
* **Live API Streams:** Dynamic, real-time queries to fetch temperature, humidity, and atmospheric conditions.
* **Manual City Search:** Fully interactive search bar with instant error-handling for invalid queries.
* **Modern UI:** Styled in a premium flat dark-mode aesthetic, completely bypassing dated default OS layouts.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Framework:** Tkinter (GUI)
* **APIs & Libraries:** OpenWeatherMap API, `requests`, `geocoder`
